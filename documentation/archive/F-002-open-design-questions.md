# F-002 — Open design questions (the `C-NN` register)

**Parent:** Project Studio
**Status:** Deferred — standing register
**Opened:** 2026-08-15 · **Closed:** —

## What this is

The pointer node for `open-questions.md` in this folder — the `C-NN` register of
design questions raised but not yet answered, each Open / Answered / Closed.

It predates the tree and is kept as one file rather than split into nodes: the
entries are questions, not work, and they are most useful read against each
other.

## How it relates to the tree

- A `C-NN` that turns into work becomes a `T-NNN` whose parent is this node.
- A `C-NN` that gets answered becomes a decision — an ADR if the rule is
  Harness-internal, a `D-NNN` if it spans products — and is marked Answered
  with a link.
- A `C-NN` blocking progress is promoted to a `B-NNN`.

It is a dictionary. Do not read it end to end; open it when something names a
`C-NN`.
